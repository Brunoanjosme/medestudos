# MedEstudos 5 (Drops)

App de estudos para residência: **Agenda** (check-in do Extensivo), **Revisão** (Drops + flashcards, modo áudio/carro offline), **Cidade** (panorama dos assuntos) e **Simulados**.

- `index.html`, `sw.js`, `manifest.json`: PWA publicado no GitHub Pages (funciona offline).
- `apps-script/`: código do backend (Google Apps Script ligado à planilha "Estudo novo").
